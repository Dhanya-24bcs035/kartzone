# KartZone – Smart E-commerce Website

A Flipkart/Amazon-style online shopping website built with **HTML, CSS and JavaScript** (single-file, no backend).

## Live Demo
https://dhanya-24bcs035.github.io/kartzone/

## Features
- Homepage with search, category strip, auto-sliding banner and deal sections
- Product listing with filters (category, price, rating) and sorting
- Product page with offers, pincode delivery check and similar products
- Cart, checkout with address validation, payment options and order tracking
- Wishlist, dark mode, and data saved in the browser (localStorage)

## Unique Features
- **Budget Buddy** – enter a budget and get the best-rated basket that fits it
- **Price History** – 12-week price chart with a "good time to buy" verdict
- **Compare Products** – compare up to 3 products side by side
- **Daily Lucky Spin** – win coupons or KartCoins once a day
- **Coupons and KartCoins** – earn rewards on every order and redeem them at checkout
- **Recently Viewed** – quick access to products you looked at

## Tech Stack
HTML5, CSS3, Vanilla JavaScript, localStorage

## How to Run
Download `index.html` and open it in any browser.

## Future Scope
User authentication, a real database and backend (Node.js/MongoDB), payment gateway integration, admin panel, and real product reviews.
